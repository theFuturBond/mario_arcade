# mario_aracde
Implementation d'un jeu de plateforme 2D type mario avec la librairie ARCADE. A jour avec la version arcade 3.3.

# Prerequis
-- Création d'un environement : 

python3 -m venv .venv

source .venv/bin/activate

-- Instalation d'arcade : 

pip install arcade

-- Lancement du jeu :

python main.py
